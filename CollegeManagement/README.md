# Система управления колледжем

Стартовый веб-проект на ASP.NET Core MVC и .NET 10. Интерфейс пока содержит обзор и планируемые разделы; рабочие данные и функции будут добавляться постепенно.

## Запуск

Требуется .NET 10 SDK.

```bash
dotnet run
```

Откройте URL, указанный в выводе команды (обычно `http://localhost:5249`).
